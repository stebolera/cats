## 1. Цель работы

Превратить статический макет из лабораторной работы № 1
в интерактивное одностраничное приложение (SPA) на чистом
JavaScript: освоить работу с DOM, обработку событий и делегирование,
клиентскую валидацию форм, архитектуру State-Driven UI и хранение
данных в localStorage.

---

## 2. Выбранная тема

**«Котолог» — каталог пород кошек** (категория «Каталоги и справочники»).

Целевая сущность — карточка породы кошки со следующими атрибутами:
название, страна происхождения, размер, тип шерсти, максимальный вес,
продолжительность жизни, описание, флаг «подходит для семей с детьми»,
изображение.

Пользователь может фильтровать каталог по шерсти и размеру, искать
по названию или стране, сортировать, добавлять новые породы через
модальное окно и удалять существующие.

## 4. Что сделано

### 4.1. HTML

Обновлён документ `index.html`:

- форма «Подбор породы» превращена в панель управления: поле поиска
  по названию или стране, фильтр по типу шерсти, фильтр по размеру
  и выпадающий список сортировки;
- контейнер карточек `#cards` оставлен пустым — все карточки пород
  генерируются JavaScript-ом;
- добавлено модальное окно `#modal` с формой `#add-form` для создания
  новой породы, включая поле загрузки изображения;
- каждое поле формы получило связанный `<label>` и блок `.error`
  для вывода текста ошибки;
- у модалки заданы `role="dialog"`, `aria-modal`, `aria-labelledby`;
- сохранена семантическая разметка (`header`, `nav`, `main`,
  `section`, `article`, `footer`) и атрибуты доступности
  (`aria-label`, `aria-live` для счётчика найденного).

### 4.2. CSS

Стили вынесены в `css/style.css` и дополнены:

- добавлены стили модального окна, подложки и анимаций открытия;
- оформлены сообщения об ошибках под полями (`.error`, `.is-invalid`);
- добавлен блок превью загруженного фото `.image-preview`;
- сохранена адаптивная вёрстка: карточки перестраиваются в 3, 2 и 1
  колонку через CSS Grid, блоки с фото — в столбик на планшете и
  телефоне;
- палитра и шрифты подключены через `@font-face` и CSS-переменные;
- цвет блоков — `#C7B08A` с прозрачностью 60%, карточек — `#F8F2E8`,
  у карточек пород — лёгкая зелёная тень.

### 4.3. JavaScript

Вся интерактивная логика вынесена в `js/app.js` и построена вокруг
единого объекта состояния `state`, который хранит массив элементов,
строку поиска, выбранные фильтры и режим сортировки. Интерфейс
перерисовывается функцией `render()` на основе актуального `state`.

Реализованы все обязательные возможности:

- динамический поиск по названию и стране породы — срабатывает
  мгновенно при вводе, регистр символов не важен;
- фильтрация по типу шерсти и размеру с пунктом «Все …» для сброса;
- сортировка по названию (А–Я, Я–А) и по весу (по возрастанию и
  убыванию), выполняется иммутабельно, исходный массив не меняется;
- модальное окно добавления новой породы; закрывается по крестику,
  кнопке «Отмена», клавише `Escape` и клику по подложке;
- форма с HTML5-валидацией (`required`, `minlength`, `maxlength`,
  `min`, `max`, `step`), проверкой через `input.validity` и текстовыми
  сообщениями под невалидными полями;
- удаление карточки через делегирование событий — один слушатель
  `click` на контейнере каталога, поиск целевой кнопки через
  `e.target.closest(...)`;
- сохранение данных в `localStorage` при добавлении и удалении,
  чтение при загрузке страницы; при пустом хранилище подгружается
  массив из 8 демонстрационных пород;
- архитектура State-Driven UI: изменение интерфейса — только через
  полную перерисовку контейнера карточек по текущему `state`.

Дополнительно реализовано:

- счётчик найденного («Показано пород: N» / «Найдено: N из M»);
- кнопка «Сбросить фильтр», возвращающая все параметры к значениям
  по умолчанию;
- загрузка фото новой породы через `FileReader` с проверкой типа и
  размера файла (максимум 1 МБ), превью и кнопкой удаления;
- активный пункт меню (scroll-spy) — текущий раздел подсвечивается
  овальной плашкой при прокрутке.

### 4.4. Требования к коду

- для вставки пользовательских данных используется только
  `textContent`, `innerHTML` не применяется нигде;
- используются только `const` и `let`, устаревший `var` не используется;
- сравнение — только строгое (`===`);
- сторонние библиотеки и фреймворки не подключены, весь функционал
  реализован на чистом JavaScript.

## 5. Проверка работы

- поиск срабатывает мгновенно при вводе в поле `#search`;
- фильтры по размеру и типу шерсти работают, пункт «Все …» сбрасывает
  соответствующий фильтр;
- сортировка переключается между 4 режимами;
- модальное окно закрывается всеми четырьмя способами (крестик,
  «Отмена», `Escape`, клик по подложке);
- при отправке пустой формы под каждым обязательным полем появляется
  сообщение об ошибке;
- после добавления новая карточка появляется в начале каталога, а
  страница прокручивается к разделу «Породы кошек»;
- при удалении запрашивается подтверждение, после которого карточка
  исчезает;
- после перезагрузки страницы данные сохраняются;
- при очистке `localStorage` снова загружаются 8 демонстрационных
  пород;
- при ширине 360 px горизонтальной прокрутки нет.
