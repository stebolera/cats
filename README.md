# Котолог — каталог пород кошек

Учебный проект по курсу веб-разработки. Первая лабораторная работа —
статическая клиентская часть веб-приложения.

## О проекте

«Котолог» — это каталог пород кошек. Пользователь может:

- просмотреть карточки пород с фотографией, описанием и характеристиками;
- сравнить породы по стране происхождения, размеру, весу и продолжительности жизни;
- воспользоваться формой подбора, чтобы отфильтровать породы по названию,
  типу шерсти, размеру, весу и совместимости с детьми;
- прочитать советы по выбору породы, уходу и содержанию.

Проект предназначен для людей, которые выбирают первую кошку или хотят
сравнить породы перед покупкой котёнка.

## Основные блоки страницы

- **Шапка** (`header.site-header`) — логотип проекта и навигация
  по разделам: «Каталог», «Подбор», «Как выбрать», «О проекте».
- **Вводный блок** (`section.hero`) — главный заголовок и краткое
  объяснение задачи проекта.
- **Форма подбора** (`section#filters`) — поиск и фильтрация пород
  по нескольким полям: название, тип шерсти, размер, максимальный вес,
  совместимость с детьми.
- **Каталог пород** (`section#breeds`) — сетка из восьми карточек.
  У каждой карточки есть изображение, название, краткое описание
  и список характеристик.
- **Текстовые блоки** — «Что важно знать о породах» и «Уход и содержание».
- **Блок «Как выбрать породу»** (`section#about`) — четыре совета
  для будущих владельцев.
- **FAQ** (`section#faq`) — частые вопросы о выборе и содержании кошек.
- **Подвал** (`footer.site-footer`) — название проекта и информация
  об учебном статусе.

## Технологии

- **HTML5** — разметка.
- **CSS3** — оформление страницы.
- **CSS Grid** — сетка карточек пород, FAQ и блок «Как выбрать».
- **Flexbox** — шапка, навигация, форма подбора и подвал.
- **Адаптивная вёрстка** — контрольные ширины 360, 768 и 1280 px.

## Доступность

- Все поля формы имеют видимые подписи `label`, связанные через `for` и `id`.
- У каждого поля есть атрибут `name` для будущей отправки данных.
- Для всех содержательных изображений задан осмысленный `alt`.
- Видимая рамка фокуса сохранена для ссылок, кнопок и полей формы —
  страницей можно управлять клавишей Tab.
- Для навигации и формы заданы `aria-label` и `aria-labelledby`.
